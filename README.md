# Moyu 摸魚（暫定名稱）

一系列「長得像 AI 聊天介面」的上班摸魚小遊戲：每局 30 秒到 3 分鐘，隨時關、隨時接；有社群功能，沒有廣告。

## 文件

| 文件 | 內容 |
|---|---|
| [docs/01-research.md](docs/01-research.md) | 市場與設計調研：老闆鍵遊戲史、AI 類遊戲前例、Wordle/NYT 分享機制、變現基準、法律風險 |
| [docs/02-game-design.md](docs/02-game-design.md) | 企劃書與劇本：介面偽裝、世界觀與主線、8 款遊戲設計（含對話劇本）、社群、收費、安全、路線圖 |
| [docs/03-mud-design.md](docs/03-mud-design.md) | 主力遊戲《B13 之龍》文字 MUD 企劃：調研、世界觀、職業、系統、四章分段實作計畫 |

## 程式

網頁版在 [`app/`](app/)：聊天外殼、老闆鍵、新手教學，主線遊戲《B13 之龍》（文字 MUD，第一章），以及四款小品：每日提示詞、算力農場、Bug 地城、建議回覆人生。線上試玩：https://pcpcchen-coder.github.io/OfficeGame/ 。說明與開發指令見 [app/README.md](app/README.md)。
