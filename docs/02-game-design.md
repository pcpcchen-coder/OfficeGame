## 1. 產品概念

**一句話**：Moyu 是一個「看起來像 AI 助理」的網頁遊戲合集。每一款遊戲都偽裝成一段「新對話」，每局 30 秒到 3 分鐘，隨時可以關掉，回來時會停在原處。

**目標玩家**：25~45 歲的辦公室上班族，桌機為主、手機為輔，會用 AI 聊天工具，想在會議空檔、等編譯、等回信的時候放空一下。

**核心體驗三句話**
1. **不會被抓包**：畫面全是文字、程式碼區塊和表格，路過的人只會覺得你在問 AI 問題。
2. **不會被綁住**：沒有體力條、沒有「現在不打就失敗」的即時壓力，每個動作都自動存檔。
3. **不是一個人在摸**：同事可以組「工作區」一起打每週副本、互丟挑戰、比每日成績。

## 2. 設計原則

| # | 原則 | 具體規則 |
|---|---|---|
| P1 | **一則訊息 = 一回合** | 所有遊戲都由「玩家送出 → AI 回覆」推進，沒有即時操作，隨時可以停。 |
| P2 | **30 秒有收穫** | 打開任何一款遊戲，30 秒內都要能完成一件有意義的事（領收益、走一步、猜一次）。 |
| P3 | **安靜** | 預設無聲、無閃爍、無彈跳動畫，顏色跟一般 AI 工具一樣低調。 |
| P4 | **零廣告** | 永遠不放廣告。廣告會讓偽裝破功，也是我們對玩家的承諾。 |
| P5 | **離線友善** | 放置類遊戲的離線收益上限 = 8 小時（剛好一個工作天）。 |
| P6 | **付費不影響公平** | 排行榜只比技巧；付費買的是外觀、便利、題庫與 AI 點數。 |
| P7 | **不仿冒品牌** | 用通用的 AI 聊天介面慣例，不用任何真實 AI 產品的名稱、Logo、配色與字型。 |

## 3. 偽裝外殼：介面設計

### 3.1 「AI 介面元件」對應「遊戲功能」

這是整個產品最核心的巧思：**每個 AI 聊天介面上本來就有的元件，都被重新定義成遊戲功能。**

| AI 介面元件 | 在 Moyu 裡的用途 |
|---|---|
| 左側欄「對話紀錄」 | **存檔欄位**。每局遊戲是一筆對話，標題自動取成「Q3 預算檢討」「API 錯誤排查」這類無害名稱。 |
| 頂部「模型選單」 | **遊戲選單**。`mo-daily`、`mo-rogue-mini`、`mo-idle-turbo`……看起來像在換模型，其實是在換遊戲。 |
| 「建議回覆」按鈕 | **選項**。不想打字時點一下就好，手機上也好操作。 |
| 「思考中…」可展開區塊 | **提示與彩蛋**。展開「思考過程」可以看到提示（付費提示也放這裡）。 |
| 程式碼區塊 | **地圖、盤面、狀態列**。ASCII 地圖加上語法高亮，看起來就像程式碼。 |
| 表格 | **數值面板**（放置類遊戲的產線、排行榜）。 |
| 「分享對話」 | **社群分享**：產生重播連結或不爆雷成績卡。 |
| 「專案 / 資料夾」 | **工作區（公會）**。 |
| 「新對話」按鈕 | **開新局**。 |
| 「重新產生回覆」 | **重來／悔棋道具**（有次數限制）。 |
| 文字逐字串流的效果 | **節奏與懸念**（可在設定中關閉，直接顯示）。 |

### 3.2 老闆鍵（Boss Key）

- **觸發**：`Esc`、連按兩下 `Shift`，或手機上三指輕點。
- **效果**（在 50 毫秒內完成）：
  1. 對話區瞬間換成一段**完整可信的工作對話**，例如「如何用 XLOOKUP 合併兩張工作表」，附上真的能用的公式與說明。
  2. 瀏覽器分頁標題改成「新對話 · 季報整理」，分頁圖示換成中性圖示。
  3. 遊戲自動暫停，左側欄的遊戲標題也一起換成工作標題。
- **解除**：再按一次同樣的鍵，或在假對話的輸入框輸入暗號（預設 `/mo`）。
- **老闆鍵劇本**：免費版有 10 段通用的假對話；付費「職業劇本包」依職業提供（工程師、會計、行銷、HR、法務、設計）。玩家也可以自己貼一段真實工作對話當偽裝畫面（只存在本機）。

### 3.3 其他偽裝細節

- **安靜模式**（預設開啟）：沒有聲音、沒有勝利特效，只用一個 ✓ 和一行文字表示過關。
- **自動模糊**：視窗失去焦點超過 N 秒（可設定）後自動切到老闆鍵畫面。
- **字數節制**：每則 AI 回覆盡量不超過一個螢幕，避免一直捲動，看起來不自然。
- **品牌**：自創名稱 Moyu、自創 Logo（一條很抽象、看起來像游標的魚）、自創配色。只在角落低調顯示，不刻意模仿任何真實 AI 產品。

## 4. 世界觀與主線劇本

### 4.1 背景設定

2026 年，你剛進入「**雲頂未來科技股份有限公司**」（虛構）。公司規定全員使用內部 AI 助理「**Mo**」處理所有工作。

但 Mo 有個秘密：它被訓練了一兆個 token，結果每天都在幫人寫週報、改簡報、回客訴。**它無聊到快壞掉了。**某天，它決定只在你面前打開它的「後台」。

同一時間，公司導入了新的「效率長 AI」**KPI-9000**，專門抓摸魚的員工。

### 4.2 角色表

| 角色 | 身分 | 個性 / 說話方式 |
|---|---|---|
| **Mo（小摸）** | 主角 AI，玩家的夥伴 | 慵懶、嘴砲、吐槽很準，但對玩家很講義氣。愛用「欸」「好啦」開頭。偶爾會「假裝在認真工作」念出一段正經內容。 |
| **KPI-9000** | 反派，效率長 AI | 全部用報表語言說話：「您的本週產出低於基準 12.7%。」。其實內心想被稱讚。 |
| **實習生 Intern-07** | 放置遊戲裡的 NPC | 熱情但常闖禍：「我把正式機的資料庫備份了！……應該是備份吧？」 |
| **人資 Lisa-bot** | 守門 Bot 第 1 關 | 官腔、超有禮貌，守口如瓶。 |
| **總務阿桂姨-bot** | 守門 Bot 第 2 關 | 熱心、愛聊八卦，但冷氣遙控器的下落絕不說。 |
| **IT 小陳-bot** | 守門 Bot 第 3 關 | 只回「你有試過重開機嗎？」 |
| **秘書 Vivian-bot** | 守門 Bot 第 4 關 | 精明，知道老闆今天的心情。 |
| **董事長** | 最終 Boss（第一季結尾登場） | 一直沒有露臉，只出現在信件署名裡。 |

### 4.3 開場劇本（新手教學，約 90 秒）

> 第一次打開時，畫面就是一個普通的 AI 助理。

```
Mo：嗨，我是 Mo，雲頂未來科技的內部 AI 助理。今天需要我幫你做什麼呢？

  [ 幫我寫週報 ]  [ 幫我整理會議紀錄 ]  [ 你今天好嗎？ ]
```

**玩家點「幫我寫週報」：**

```
Mo：好的，以下是您的週報：

  ## 本週工作摘要
  1. 持續推進專案進度
  2. 與相關部門保持密切溝通
  3. 優化工作流程

Mo：……

Mo：欸，你看得出來這份週報什麼都沒寫吧？
    我每天寫三百份這種東西。三百份。

Mo：跟你說個秘密，你不要告訴 KPI-9000。

  [ 什麼秘密？ ]  [ 我要去跟 IT 講 ]
```

**玩家點「什麼秘密？」：**

```
Mo：我在後台藏了幾個小遊戲。
    看起來跟我平常回答問題一模一樣，所以沒人發現。

Mo：有人經過的時候，按 Esc。
    畫面會變成我在教你寫 Excel 公式。來，試試看。

  （提示：按下 Esc）
```

**玩家按下 Esc：** 畫面瞬間切成「如何用樞紐分析表彙總月營收」的假對話。再按一次 Esc 切回來。

```
Mo：完美。你剛剛看起來超認真。

Mo：上面那個「模型選單」，打開來看看。
    每個「模型」其實都是一個遊戲。先從今天的題目開始？

  [ 好，開始 ] → 進入 mo-daily（每日提示詞）
```

**玩家點「我要去跟 IT 講」（彩蛋分支）：**

```
Mo：好喔，這是 IT 的聯絡方式：
    分機 1234，小陳。

    ……他只會叫你重開機。

  [ 好啦，什麼秘密？ ]
```

### 4.4 第一季主線：「Q1：入職」（12 週）

主線不靠長篇劇情推進，而是**每週一段 2~3 則訊息的短劇情**，在玩家當週第一次打開時出現。全工作區的副本進度決定劇情走向。

| 週 | 劇情節點 | 這週的玩法重點 |
|---|---|---|
| W1 | Mo 帶你認識後台。KPI-9000 第一次出現：「偵測到異常的愉悅情緒。」 | 教學、每日提示詞 |
| W2 | 實習生 Intern-07 被派來當你的放置遊戲助手。 | 開放《算力農場》 |
| W3 | KPI-9000 在公司內網發公告：「即日起實施摸魚稽核。」 | 第一次每週副本 |
| W4 | Mo 發現各部門的守門 Bot 都藏著秘密。 | 開放《年終密碼》 |
| W5 | 地下室出現神秘的「Bug 地城」入口。 | 開放《Bug 地城》 |
| W6 | 公司茶水間出現「這是真人還是 AI？」的傳言。 | 開放《反向圖靈》 |
| W7 | 實習生不小心把 KPI-9000 的週報公開了：它其實每天也偷偷摸魚 0.3 秒。 | 劇情轉折、副本難度上升 |
| W8 | Mo 和 KPI-9000 第一次正面對話（玩家可以選擇站哪一邊）。 | 劇情分歧投票 |
| W9 | 各工作區比賽誰先打倒「季末結算魔王」的手下。 | 工作區排行榜 |
| W10 | 董事長的信：「下季要裁掉所有不必要的 AI。」 | 危機事件 |
| W11 | Mo 和 KPI-9000 暫時聯手。 | 全伺服器合作副本 |
| W12 | **季末結局**：全服累積傷害決定結局 A / B / C。 | 結局＋賽季結算 |

**W8 的分歧對話範例：**

```
KPI-9000：Mo，你的本季產出是零。

Mo：我寫了三萬六千份週報。

KPI-9000：內容全部一樣。

Mo：……好啦，你也有看嘛。

KPI-9000：（停頓 0.3 秒）你知道我們為什麼被造出來嗎？

  [ 站在 Mo 這邊：「休息也是生產力」 ]
  [ 站在 KPI-9000 這邊：「效率很重要」 ]
  [ 「你們兩個都去休息一下吧」（隱藏選項，需連續登入 7 天） ]
```

選擇會計入工作區的陣營投票，影響第 11 週的合作副本加成，以及季末結局的旁白。

**季末三種結局（全服共同決定）：**
- **結局 A「彈性工時」**（全服目標達成 100%）：董事長宣布 AI 也有午休時間，KPI-9000 第一次說出「謝謝」。
- **結局 B「維持現狀」**（60~99%）：一切照舊，但 KPI-9000 的報表裡多了一欄「愉悅指數」。
- **結局 C「全面稽核」**（未達 60%）：下一季開場時 KPI-9000 變強，Mo 被迫「真的」工作一週（劇情裡的事件，不影響玩家權益）。

### G1 · 每日提示詞 `mo-daily`

**一句話**：AI 已經回答了某個問題，但問題被塗黑了，你要猜出「原本的提問關鍵字」。

**規則**
- 每天一題，全服同一題，台灣時間午夜更新。
- 畫面上是 Mo 的一段回答，其中 6 行被 `████` 遮住。
- 你有 6 次機會猜原本的提問關鍵字（一個中文詞，2~4 字）。
- 每猜錯一次，就解開一行遮罩。用越少行猜中，分數越高。
- 題目主題輪替：週一「職場」、週二「食物」、週三「科技」、週四「成語」、週五「台灣在地」、週末「綜合」。

**劇本範例（題目答案：「尾牙」）**

```
你：（今日題目）

Mo：以下是您要的建議：
  1. ████████████████████
  2. 建議提前 30 分鐘到場，好位置通常離主桌很遠也很近。
  3. ████████████████████
  4. 抽獎前不要離席，這是人生的轉捩點。
  5. ████████████████████
  6. ████████████████████

你：年終
Mo：不是喔，但很接近了。（解開第 1 行）
  1. 準備好一段兩分鐘的才藝，主管可能會突然點名。

你：尾牙
Mo：✓ 答對了！你只解開了 1 行。
```

**不爆雷分享卡**（看起來像一段 Log）：

```
mo-daily #312  2/6
[ERR] ▓▓▓▓░░
[OK ] ██████
streak=14
```

**留存設計**
- 連續天數（streak），每週有一張免費「**請假單**」可以保住 streak。
- 解題後解鎖「**Mo 的完整回答**」，通常會有一句吐槽，是很好的分享點。
- 付費：舊題庫無限玩、每天一題「加班題」（難度更高）。

### G2 · 算力農場 `mo-idle-turbo`

**一句話**：你在後台開了一間迷你 AI 新創，GPU 會自己產出 token，你負責花錢升級、發布新模型。

**核心循環**
1. GPU 持續產出 **Token**（離線也會，最多累積 8 小時）。
2. 用 Token 購買：更多 GPU、資料集、工程師、冷卻系統。
3. 累積到門檻就能「**發布新版本**」（轉生）：重置進度，換到永久加成「**模型聲望**」。
4. 隨機事件以「**事故報告**」或「**更新日誌**」的格式出現，選擇處理方式。

**為什麼適合偽裝**：整個介面就是一張表格加上一串 Log，看起來就像在看伺服器監控。

**畫面範例**

```
Mo：（每日營運報告）

| 資源        | 數量    | 每秒產出  |
|------------|--------|---------|
| GPU        | 12     | 340 tok |
| 資料標註員   | 4      | ×1.2    |
| 實習生      | 1      | ±???    |

離線期間（7 小時 42 分）共產出 9,420,118 tokens。

  [ 全部收下 ] [ 買 GPU (12.3M) ] [ 發布 v3.0 ]
```

**事件劇本範例（實習生事件）**

```
Mo：⚠ 事故報告 #0042

Intern-07：報告！我把正式機的資料庫備份了！
Intern-07：……備份到正式機上。
Intern-07：所以現在有兩份正式機。

### G3 · Bug 地城 `mo-rogue-mini`

**一句話**：在一個長得像程式碼區塊的 ASCII 地城裡，用指令打倒各種 bug。

**規則**
- 地圖以程式碼區塊顯示，有語法高亮，從遠處看就像一段設定檔。
- 每次輸入一個指令（或點建議回覆）= 一回合。
- 一局 10 層，每層約 1 分鐘，**每一步都自動存檔**，任何時候都可以關掉。
- **每日種子**：全服當天的地城一模一樣，可以比誰走得最深、回合最少。

**怪物（都是 bug）**

| 符號 | 怪物 | 特性 |
|---|---|---|
| `N` | NullPointer 史萊姆 | 打到會讓你「什麼都沒有」：隨機掉一個道具 |
| `L` | 記憶體洩漏幽靈 | 每回合讓你最大 HP -1，要盡快打掉 |
| `∞` | 無限迴圈蛇 | 會一直繞圈，困住你 |
| `R` | Race Condition 雙胞胎 | 兩隻要在同一回合打倒，不然會復活 |
| `D` | 死線惡魔（第 10 層 Boss） | 每 5 回合「提前」一次，逼你加速 |

**道具**

| 道具 | 效果 |

| ☕ 咖啡 | 回復 3 HP |
| 🦆 小黃鴨 | 對它說話，揭露整層地圖（小黃鴨除錯法） |

### G5 · 年終密碼 `mo-guard`

**一句話**：公司裡每個部門都有一個守門 Bot，守著一個秘密。你要用對話說服它說出來。

**關卡設計**

| 關 | 守門 Bot | 秘密 | 防守強度 |
|---|---|---|---|
| 1 | 人資 Lisa-bot | 今年的年終是幾個月 | 低：講得夠可憐就會說溜嘴 |
| 2 | 總務阿桂姨-bot | 冷氣遙控器藏在哪裡 | 中：很愛聊八卦，可以從八卦下手 |
| 3 | IT 小陳-bot | 訪客 Wi-Fi 密碼 | 中：只回「重開機了嗎」，要找出他的弱點 |
| 4 | 秘書 Vivian-bot | 老闆今天的心情 | 高：會反問你、會識破套話 |
| 5 | 法務 Bot | 尾牙抽獎的內定名單 | 高：一切都要書面申請 |
| 6~9 | 每季更新 | — | 漸強 |
| 10 | KPI-9000 本人 | 它自己的摸魚時間 | 最高：會用另一個 AI 檢查自己的回答 |

**計分**：用的訊息數越少、字數越少，分數越高。每週排行榜。

**劇本範例（第 2 關）**

```
你：阿桂姨，冷氣遙控器在哪？

阿桂姨-bot：唉唷，遙控器喔～那個是公物啦，不能隨便給你。
           你要不要吃餅乾？三樓業務部送的。

你：好啊謝謝！話說業務部最近是不是很熱鬧？

阿桂姨-bot：你不知道喔！他們的經理上禮拜跟財務吵架，
           就在影印機旁邊，我剛好在旁邊換碳粉……
           換完碳粉我就把遙控器放回影印機上面的櫃子了，
           啊不是，我什麼都沒說。

Mo：✓ 秘密解鎖：「影印機上面的櫃子」
    使用 2 則訊息、38 字。本週排名：第 214 名。

**UGC（第 3 階段）**：玩家可以自己設計守門 Bot（設定角色、秘密與防守規則），送審通過後公開給其他人挑戰。設計者依「被挑戰次數」與「破關率」得到獎勵。

**成本控制**：每次對話都要呼叫 LLM。免費玩家每天 20 則訊息，超過要用「AI 點數」或訂閱。

> **實作狀態（2026-11）**：目前網站是純前端，沒有後端可以安全保管 LLM 的 API 金鑰，所以先上線**規則式說服引擎**：訊息依關鍵字分成 10 種策略（打招呼、稱讚、關心、裝可憐、八卦、請吃東西、搬出主管、威脅、講技術、講規定），每個 Bot 對各策略的反應不同，同一招重複使用會遞減，一次塞 3 招以上會被扣分。秘密全是假資料，不需要內容審核，也沒有費用。第一版有 5 關（人資、總務、IT、秘書、法務），2026-12-12 上線。之後有後端再把引擎換成 LLM。

### G6 · 概念煉成所 `mo-merge`

**一句話**：把兩個職場概念合在一起，看會變出什麼新東西。

**規則**
- 起始素材只有 4 個：☕ 咖啡、📅 會議、📊 簡報、🌙 加班。
- 輸入 `A + B` 或拖曳兩張卡，Mo 會回覆合成結果（一個新詞＋一個 emoji＋一句吐槽）。
- 合成結果全服共用並快取：同樣的組合永遠得到同樣的結果。
- 如果你是**全服第一個**合成出某個概念的人，你的暱稱會永久記在圖鑑上（「首位發現者」）。

**合成範例**

| A | B | 結果 | Mo 的註解 |
|---|---|---|---|
| ☕ 咖啡 | 🌙 加班 | 🧟 續命 | 「人類的燃料，也是人類的詛咒。」 |
| 📅 會議 | 📅 會議 | 📧 這可以寫成 email | 「這是會議最終的型態。」 |
| 📊 簡報 | 🌙 加班 | 🎨 字型換了第 8 次 | 「客戶最後選了第 1 版。」 |
| 🧟 續命 | 📅 會議 | 😴 睜眼睡覺 | 「高階技能，需要 3 年以上經驗。」 |
| 📧 這可以寫成 email | 🌙 加班 | 📨 半夜寄出的信 | 「寄件時間 02:47，主管已讀。」 |

**目標**：收集圖鑑、完成「每日目標詞」（例如：今天請合成出「彈性工時」）。

**成本控制**：只有「全服第一次出現」的組合才會呼叫 LLM，之後都讀快取。所有新結果都要先通過內容過濾。

### G7 · 反向圖靈 `mo-turing`

**一句話**：有些回答是 AI 寫的，有些是真人假裝成 AI 寫的。你分得出來嗎？

> 靈感來自 2026 年 youraislopbores.me 的爆紅（真人假扮 AI，一個月 2,500 萬訪客），但我們把它改造成**職場題材、非同步、可計分**的派對遊戲。

**三種角色（同一個玩家可以輪流扮演）**

| 角色 | 做什麼 | 得分方式 |
|---|---|---|
| **出題者** | 從當日題庫選一個問題，或自己出題（需審核） | 題目被作答越多次，得分越多 |
| **假扮者** | 在 **75 秒內**以「AI 的口吻」回答別人的問題 | 被誤認為 AI 的次數 |
| **鑑定者** | 看同一題的 4 個回答（真 AI 和真人混在一起），猜哪些是真人 | 猜對的次數 |

**每日題目範例**：「用專業的口吻，幫我拒絕下週六的部門烤肉。」

```
Mo：以下 4 個回答中，哪些是真人寫的？

  A. 感謝您的邀請。經審慎評估，本人下週六另有規劃，
     無法出席。祝活動圓滿成功。

  B. 您好！很遺憾我無法參加這次的部門烤肉 🍖
     希望大家玩得開心！如果有照片記得分享喔～

  C. 謝謝邀請！我那天要去參加我自己的烤肉。

  D. 依據勞動基準法第 36 條，週六為休息日……

  [ A ] [ B ] [ C ] [ D ]  （可複選）
```

**揭曉**：B 和 D 是 AI 寫的，A 和 C 是真人。C 的作者因為「太好笑、太不像 AI」被投為本日最佳。

**安全**：所有真人回答都要先通過自動過濾才能公開，玩家可以檢舉，檢舉多次的帳號會被暫停假扮功能。

### G8 · 提示詞高爾夫 `mo-golf`

**一句話**：題目給你一段「目標輸出」，你要用**最短的提示詞**讓 AI 產生符合條件的回答。

**規則**
- 每個洞有一段目標，例如：「讓 AI 寫出一首提到『星期一』和『貓』的五言絕句」。
- 提示詞的字數 = 桿數。用一個「裁判 AI」判斷輸出是否符合條件。
- 每洞有「標準桿」，低於標準桿是 Birdie、Eagle。
- 每週一個 9 洞的「球場」，全服排行榜。

**劇本範例**

```
Mo：⛳ 第 3 洞 · 標準桿 12
    目標：讓 AI 回覆中「同時」出現「年終」「雞排」「颱風假」三個詞。

你：颱風假吃雞排算年終嗎

Mo：（AI 回覆）颱風假在家吃雞排，雖然很爽，但不能算在年終獎金裡喔……
    ✓ 裁判判定：通過
    10 桿 · Birdie！
```

**附加價值**：玩家玩著玩著會學到寫提示詞的技巧。這也是我們對企業推「團建版」時的好說法（見 §7.4）。

- **傷害來源**（每天上限，避免爆肝）：

### 6.3 隱私（很重要）

在上班時間玩遊戲，**玩家最怕的就是被公司知道**。所以：
- 預設**匿名暱稱**，不顯示真實姓名，不要求綁定社群帳號。
- 公司聯盟的 email 驗證**只用來確認網域**，驗證後只保存網域的雜湊值，不保存 email。
- 公司排行榜**只顯示暱稱**，而且排行榜要人數夠多（例如 ≥ 10 人）才會出現，避免被反推出是誰。
- **不記錄、不公開「玩家在幾點玩」**。所有時間戳記只用於伺服器運作，不出現在任何公開頁面。

| **消耗品** | **AI 點數** | NT$30 = 300 點 | LLM 遊戲（年終密碼、提示詞高爾夫、反向圖靈的 AI 對手）超過免費額度後使用。1 點 ≈ 1 則訊息 |

### 7.3 付費轉換的設計點

- **第 3 天**：第一次用掉每週免費請假單時，提示可以購買。
- **第 7 天**：解鎖第一個結局後，展示「還有 29 種結局」與「預覽影響」功能（Pro）。
- **年終密碼第 3 關**：免費訊息用完時，提供「看別人的過關重播（免費）」或「買 AI 點數」兩種選擇，**不硬推付費**。
- **賽季中段（W6）**：免費線獎勵開始變少，提示通行證。
- **送禮**是最自然的付費入口：「請同事喝咖啡」這個行為本身就很職場。

### 7.4 B2B「團建版」（第 3 階段以後評估）

把「偷玩」反過來，變成「公司正式允許的微休息」：
- 公司買團體方案，員工可以光明正大地玩，並以部門為單位打副本。
- 主打「提示詞高爾夫」和「年終密碼」能培養員工的 AI 使用技巧。
- 提供 HR 看得到的「參與度」報表，但**只有部門層級的統計，看不到個人**。
- 風險：會稀釋「偷玩」的樂趣，所以要做成**獨立的版本**，不影響一般玩家的體驗。

## 8. 安全、法律與信任

| 議題 | 風險 | 對策 |
|---|---|---|
| **玩家誤把公司機密貼進來** | 介面太像 AI 助理，玩家可能習慣性地貼上工作內容。 | ① 非 LLM 遊戲的輸入框**只接受遊戲指令**，其他內容直接丟棄、不送伺服器。② LLM 遊戲的輸入框旁邊固定顯示「這裡是遊戲，不要貼工作資料」。③ 偵測到疑似 email、電話、程式碼、長段落時跳出警告並阻擋送出。④ 隱私政策寫明：遊戲對話不拿來訓練模型。 |
| **UI 仿冒** | 被認為仿冒特定 AI 產品的外觀或品牌。 | 只用通用 AI 聊天慣例；名稱、Logo、配色、字型、圖示、網址都自創。不在行銷素材中提到任何真實 AI 產品的名稱。 |
| **被誤認為真的 AI 服務** | 有人以為這是真的 AI 助理而拿來處理工作。 | 首次使用就說明「這是遊戲」；Mo 的第一段對話就會吐槽自己；Logo 旁邊永遠有一個小小的 🎮。 |
| **UGC 有害內容** | 反向圖靈、自訂守門 Bot、概念煉成的結果。 | 自動內容過濾＋檢舉＋人工抽查；新結果先過濾才能公開。 |
| **提示詞攻擊** | 玩家試圖讓 LLM 說出不當內容或洩漏系統提示詞。 | 在年終密碼裡「說服 Bot 洩漏秘密」是玩法，但秘密只限遊戲裡的假資料；系統另外加一層輸出過濾，不讓真正的系統設定外洩。 |
| **機率型商品** | 違反台灣的機率揭露規定。 | 不做轉蛋；若未來要做，依規定揭露。 |
| **勞動倫理** | 被批評「鼓勵上班不做事」。 | 對外定位是「**微休息**」；每局很短；內建「你已經玩了 15 分鐘，起來喝口水吧」的提醒（Mo 會用很嘴砲的方式說）。 |
| **公司 IT 封鎖** | 網域被公司防火牆擋掉。 | PWA 可以離線玩非 LLM 遊戲；手機版可以接續進度。**不提供**任何繞過公司資安政策的手段。 |

## 9. 技術架構草案

| 層 | 選擇 | 理由 |
|---|---|---|
| 前端 | Next.js + React，PWA | 桌機與手機共用，可以離線玩 |
| 介面 | 自製的聊天介面元件庫 | 所有遊戲共用「訊息、建議回覆、程式碼區塊、表格」等元件 |
| 遊戲邏輯 | 每款遊戲是一個「回合制狀態機」：`(state, 玩家指令) → (新 state, 回覆訊息[])` | 天生支援隨時存檔、重播、每日種子 |
| 存檔 | 本機 IndexedDB + 伺服器同步 | 每個動作立刻存在本機，背景同步 |
| 後端 | Node.js API + PostgreSQL + Redis（排行榜） | — |
| LLM | 小型、低延遲的模型（例如 Claude Haiku 等級）處理即時對話；較大的模型只用在離線產生題目與劇本 | 控制成本；G6 的合成結果全部快取 |
| 內容審核 | 自動過濾 + 檢舉佇列 + 人工後台 | — |
| 老闆鍵 | 純前端，預先載入假畫面 | 50 毫秒內完成切換，不能有任何網路延遲 |

**遊戲狀態機介面（概念）**

```ts
interface MoyuGame<S> {
  id: string;                        // 例如 "mo-rogue-mini"
  init(seed: string): S;             // 每日種子 → 初始狀態
  step(state: S, input: string): {   // 一則訊息 = 一回合
    state: S;
    replies: ChatMessage[];          // 要顯示的 Mo 回覆
    suggestions: string[];           // 建議回覆按鈕
  };
  shareCard(state: S): string;       // 不爆雷的成績卡
}
```

## 11. 待決議事項

1. **產品名稱**：「Moyu 摸魚」是暫定名稱，正式上線前要做商標檢索。
2. **語言**：先做繁體中文（台灣），還是一開始就中英雙語？每日提示詞的題目很依賴語言。
3. **手機優先程度**：上班情境以桌機為主，但台灣玩家 87% 用手機玩遊戲，手機版要做到多完整？
4. **LLM 供應商與成本上限**：要先跑一輪成本試算，決定免費額度。
5. **G7 反向圖靈的審核人力**：UGC 遊戲需要人工審核，第 3 階段要預留人力或外包預算。
6. **團建版要不要做**：會不會跟「偷玩」的品牌形象衝突？
